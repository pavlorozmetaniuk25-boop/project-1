Генератор паролів

Опис проєкту

Генератор паролів — це консольна програма, написана мовою C++. Вона створює випадкові паролі заданої довжини, перевіряє їхню складність і зберігає згенерований пароль у текстовий файл.

Можливості програми

- Генерація випадкового пароля.
- Перевірка складності пароля.
- Збереження згенерованого пароля у файл "password.txt".
- Перевірка введеної довжини пароля (мінімум 8 символів).

Структура проєкту

- "main.cpp" — головна функція програми та взаємодія з користувачем.
- "generator.cpp" — реалізація генерації паролів.
- "generator.h" — оголошення функції генерації паролів.
- "checker.cpp" — реалізація перевірки складності пароля.
- "checker.h" — оголошення функції перевірки складності пароля.
- "PasswordGenerator.exe" — готовий виконуваний файл програми.

Вимоги

Для компіляції програми потрібен компілятор C++ (C++11 або новіший).

Як скомпілювати програму

Відкрий термінал у папці з файлами проєкту та виконай команду:

g++ -std=c++11 main.cpp generator.cpp checker.cpp -o PasswordGenerator.exe

Як запустити програму

На Windows двічі натисни на "PasswordGenerator.exe" або запусти його з термінала:

.\PasswordGenerator.exe

Програма попросить ввести довжину пароля (не менше 8 символів), згенерує пароль, покаже оцінку його складності та збереже пароль у файл "password.txt".
